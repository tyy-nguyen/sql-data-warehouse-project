# Data Warehouse and Analytics Project

Hey everyone, This is the **Data Warehouse and Analytics Project** repository! 🧑‍💻
This project is a way for me to start learning the skills necessary to plan and develop a data warehouse where I can use external sources
that'll go through an ETL (Extraction, Transformation, and Load) to provide actionable insights.
This project is inspired by DataWithBaraa and I'm looking for a way to elevate what I've learned to use in real-world industry.
